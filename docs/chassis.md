麦轮：
设计
    通过自由旋转滚棒方向的设计改变摩擦力的方向（保留了滚棒轴线的摩擦力，消除了垂直于轴向的摩擦力）
    通过四个轮子的合力控制运动方向和旋转（运动通过合力，旋转通过创造扭矩）
解算：
    我们要解决什么问题？
    遥控器给定横向vx、纵向xy、旋转的分量w，然后我们要通过解算，得到每一个轮子转动的速度
    1.用向量描述小车中心运动状态（平动加转动）
    2.投影到滚棒的方向
    3.再从投影反推到轮子的角速度
    4.除以半径得到电极的线速度
数学过程
    略
    v_FL =  vx − vy − ω(a+b)
    v_FR =  vx + vy + ω(a+b)
    v_RL =  vx + vy − ω(a+b)
    v_RR =  vx − vy + ω(a+b)
    其中ω为正数的时候表示逆时针

全相轮
    原理和麦轮差不多
    只不过滚棒方向和移动方向一样
    优势：传动效率更高，省功率
    劣势：横向刚度低，一撞就飞
    数学推导：
    v_FL = ( vx − vy − ω(a+b) ) / √2
    v_FR = ( vx + vy + ω(a+b) ) / √2
    v_RL = ( vx + vy − ω(a+b) ) / √2 
    v_RR = ( vx − vy + ω(a+b) ) / √2 
舵轮
    先转向，再前进（实际上是边转边走，所以转角大的时候要减速，或者就近旋转）
    数学推导：
    θ_i = atan2(v_iy, v_ix)
    v_i = √(v_ix² + v_iy²)

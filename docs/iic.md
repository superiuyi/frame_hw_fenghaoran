AI总结：
## 1. I²C 是什么

### 1.1 全称
    Inter-Integrated Circuit（集成电路总线）

### 1.2 两根线
    SCL  时钟
    SDA  数据

### 1.3 工作方式
    开漏输出 + 上拉电阻 → 实现"线与"
    主机发起，从机靠【地址】被选中

### 1.4 时序
    起始条件：SCL 高时 SDA 由高变低
    停止条件：SCL 高时 SDA 由低变高
    每传 1 字节，接收方拉低 SDA 应答（ACK）

## 2. I²C 的特点

    半双工（同一时刻只能一个方向）
    同步（有 SCL 时钟线）
    多点（靠 7 位/10 位地址区分）
    速度：标准 100kHz / 快速 400kHz / 高速 3.4MHz
    有应答机制（能知道对方收到没）
    省引脚
    开漏 + 上拉 → 电平转换方便

## 3. 为什么用开漏 + 上拉？

    开漏：只能把线拉低，不能主动拉高
    上拉电阻：把线拉回高电平
    线与：任何一个设备拉低，整条线就是低
    → 实现"时钟同步"和"总线仲裁"

## 5. SPI 与 I²C 对比

    | 项目     | SPI              | I²C            |
    | 线数     | 4                | 2              |
    | 双工     | 全双工           | 半双工         |
    | 选设备   | 片选             | 地址           |
    | 输出方式 | 推挽             | 开漏 + 上拉    |
    | 速度     | 可达几十 MHz     | 100k/400k/3.4M |
    | 应答     | 无               | 有 ACK         |
    | 多设备   | 受片选数量限制   | 地址够就能挂   |
    | 适用     | 高速、板内       | 低速、多设备   |

## 6. 一句话总结

    SPI 快但费引脚、无应答；
    I²C 省引脚、有应答，但速度慢、是半双工。
